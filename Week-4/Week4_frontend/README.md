# Blog App Frontend

HTML, CSS, and JavaScript user interface for blog application.

## Pages

- **index.html** - Main landing page with articles
- **emp.html** - Author/Employee management
- **flex.html** - Layout examples

## Styling

- **style.css** - Main styles
- **emp.css** - Employee page styles  
- **flex.css** - Flexbox utilities

## Features

- Responsive design
- Dynamic UI with JavaScript
- Article display and comments
- User authentication

## Tech Stack

- HTML5, CSS3, JavaScript, Flexbox

## Notes

Ensure backend server is running on `http://localhost:3000` for API calls.
